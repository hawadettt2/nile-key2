# Forensic Audit Workflow

## Purpose
Execute a complete forensic audit of the project state before any change.

## Steps
1. Load the `forensic-audit` skill
2. Read INSTRUCTIONS.md and project rules
3. Identify the incident or area under audit
4. Gather all relevant evidence: logs, tests, code, runtime output
5. Document the current state with evidence references
6. Trace the root cause through the codebase
7. Record findings in a structured format
8. Present evidence-based conclusions

## Output
- Evidence log with file paths and line numbers
- Root cause analysis
- Recommended minimal fix scope
