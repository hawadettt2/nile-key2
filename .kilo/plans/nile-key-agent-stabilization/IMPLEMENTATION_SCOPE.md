## 1. نطاق المرحلة الثالثة

**الهدف:** تطبيق التصميم المعتمد لمنظومة الوكلاء (التعريفات + الصلاحيات + المسارات) وفق `TARGET_ROLE_CARDS.md` و`TARGET_PERMISSION_MATRIX.md` و`SOURCE_OF_TRUTH_DECISION.md`.

**يدخل:**
- تعديل **تعريفات الوكلاء** (mode، prompt، permission) في ملفات المشروع.
- معالجة التعريفات المكررة/المتعارضة (بعد إثبات البديل).
- إضافة توجيه عربي صريح.
- ضبط حدود Bash/Edit/Write/Task.
- تحديث وثائق الحوكمة (إذا كانت ضمن النطاق).

**يخرج:**
- تعديل تطبيق Nile Key نفسه (الكود، الواجهة، قاعدة البيانات).
- تعديل إعدادات Kilo العامة (`~/.config/kilo/kilo.jsonc`).
- تعديل قواعد المشروع (`.kilocode/*`، `AGENTS.md`).
- أي تغيير برمجي/تشغيلي خارج تعريفات الوكلاء.

## 5. التعامل مع التعريفات العامة القديمة

- **لا حذف قبل إثبات بديل:** أي تعريف global (architect, data, frontend-specialist, test-engineer, forensic-audit, incident-remediation, general) يُعامل كـ**legacy**.
- **المعالجة:** يُرحَّل/يُحذف **بعد إثبات** أن البديل (project) يغطيه.
- **التنفيذ:** أي حذف/ترحيل global → **قرار مستقل من المالك** (خارج التنفيذ العادي).
- **التوثيق:** أي تعريف مستثنى من Git → **يُوثّق**.
