# UAT-01 — تسجيل الدخول ببيانات صحيحة

## المعلومات الأساسية

| الحقل | القيمة |
|-------|--------|
| **المرحلة** | Phase 1: Authentication |
| **رقم العنصر** | 1 |
| **الهدف** | التحقق من أن تسجيل الدخول ببيانات صحيحة ينجح ويوجه إلى الصفحة الرئيسية |

## خطوات التنفيذ

1. افتح المتصفح واذهب إلى: `http://localhost:3000/login`
2. أدخل **Username**: `uat_owner`
3. أدخل **Password**: [6-digit numeric password provided by Project Owner]
4. اضغط زر **"Sign In"** أو **"تسجيل الدخول"**

## النتيجة المتوقعة

1. يتم التوجيه إلى `/` (الصفحة الرئيسية)
2. تظهر الصفحة الرئيسية بدون أخطاء
3. يظهر اسم المستخدم في Sidebar

## التحقق من Network

1. افتح DevTools → Network
2. ابحث عن طلب `POST /api/v1/auth/login`
3. تحقق من:
   - **Status:** `200 OK`
   - **Response:** يحتوي على `access_token` و `refresh_token`

## التحقق من Console

1. افتح DevTools → Console
2. تحقق من عدم وجود أخطاء حمراء (red errors)
3. لا توجد أخطاء CORS أو 401/403 غير متوقعة

## تحديد PASS/FAIL/BLOCKED/N/A

| النتيجة | الشرط |
|---------|--------|
| **PASS** | تم تسجيل الدخول بنجاح وتوجيه إلى `/` بدون أخطاء |
| **FAIL** | فشل تسجيل الدخول أو توجيه خاطئ أو أخطاء Console |
| **BLOCKED** | لا يمكن الوصول إلى `/login` أو الخادم غير متاح |
| **N/A** | لا ينطبق |
