**Required additions to `.env.example`:**
- `APP_NAME=Nile Key API`
- `APP_VERSION=1.0.0`
- `DEBUG=False`
- `LETME_API_ID=your-letme-id`
- `LETME_API_PASSWORD=your-letme-password`
- `SENDCLOUD_PUBLIC_KEY=your-sendcloud-public-key`
- `SENDCLOUD_SECRET_KEY=your-sendcloud-secret-key`

- `ETA_CLIENT_SECRET=your-eta-client-secret`
- `ETA_BASE_URL=https://api.invoicing.eta.gov.eg`

**Note on `ALLOWED_ORIGINS`:** `config.py` defaults to `["*"]` while `.env.example` lists specific origins. Document this discrepancy; do not change `config.py` default in WP-08 (that is a security decision for a separate work package).

**Validation steps:**
1. Parse `config.py` and extract all `BaseSettings` fields.
2. Verify every non-defaulted field appears in `.env.example`.
3. Verify every field in `.env.example` corresponds to a `config.py` field.
4. Run `python -c "from app.core.config import Settings; Settings()"` with `.env.example` values to confirm no validation errors.

**Rollback strategy:**
- `git checkout -- backend/.env.example`
