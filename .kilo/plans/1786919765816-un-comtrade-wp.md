## 1. الهدف والدافع المعرفي

### 1.1 الهدف

إنهاء تنفيذ UN Comtrade External Source Adapter كخامس مزود خارجي مُنفَّذ (السادس المسجل في البورتفوليو)، وتحويله من "كود موجود بدون تسجيل/إعداد" إلى مزود مُنتج قابل للاستعلام عبر Registry.

### 1.2 الدافع المعرفي

| Knowledge Family | Score الحالي | Score المستهدف | الفجوة |
|------------------|-------------|----------------|--------|
| **Trade Intelligence** | 7/10 | 9/10 | UN Comtrade يملأ فجوة **Official Global Trade Statistics** |
| Provider Count | 5 مسجَّل | 6 مسجَّل | المزود السادس ضمن السقف الحالي 4–6 |

UN Comtrade يغطي فجوة لا يغطيها TradeData (تجاري) ولا GCC-Stat (إقليمي):
- إحصاءات تجارية bilateral رسمية صادرة عن UN Statistics Division
- تغطية 200+ دولة
- بيانات سنوية/شهرية بتصنيف HS/SITC/BEC
- مصدر رسمي مجاني (Preview API) يعلو على المصادر التجارية من حيث **Authority Level**

**مبدأ Knowledge Coverage > Provider Count:** إضافة المزود السادس ضمن السقف الحالي مبررة بزيادة 2 نقاط في Trade Intelligence، وليس بتكدير عددي.

## 4. Provider/Adapter Boundary

```
┌─────────────────────────────────────────────────────────┐
│           KnowledgeProviderRegistry ( unchanged )         │
│   registry.register("un-comtrade", adapter_instance)     │
└──────────────────────────┬──────────────────────────────┘
                           │ uses
                           ▼
┌─────────────────────────────────────────────────────────┐
│   UnComtradeExternalSourceAdapter                         │
│   (KnowledgeProvider) — owns:                             │
│   • _build_request()  → context → API params             │
│   • _transform()      → raw → DEM knowledge shape        │
│   • _compute_confidence() → confidence score             │
│   • get_sources()     → source metadata                  │
└───────────────────────┬─────────────────────────────────┘
                        │ delegates HTTP
                        ▼
┌─────────────────────────────────────────────────────────┐
│   UnComtradeApiClient                                     │
│   • _request_with_retry() → 429/5xx/network backoff      │
│   • _headers()          → optional API key header         │
│   (httpx only — no business logic)                        │
└───────────────────────┬─────────────────────────────────┘
                        │ HTTP
                        ▼
              UN Comtrade REST API
              comtradeapi.un.org
```

**الضوابط:**
- الـAdapter لا يصل مباشرة لـ DEM core
- الـClient لا يحتوي على منطق عمل
- التسجيل عبر Registry فقط
- التكوين عبر `config.py` فقط (لا hardcoded)

## 5. مصادر UN Comtrade و API Access

### 5.1 المصدر الرسمي

| الحقل | القيمة |
|-------|--------|
| **الموفر** | UN Comtrade API (`comtradeapi.un.org`) |
| **السلطة** | UN Statistics Division — UN Statistics Division |
| **نوع البيانات** | إحصاءات تجارية bilateral رسمية |
| **التغطية** | 200+ دولة |
| **API Base URL** | `https://comtradeapi.un.org` |
| **التوثيق** | `https://uncomtrade.org/docs/un-comtrade-api/` <br> `https://comtradedeveloper.un.org/` |

### 5.2 نقاط النهاية (Endpoints)

| Endpoint | الاستخدام | Auth |
|----------|-----------|------|
| `/public/v1/preview/{type}/{freq}/{cl}` | Preview API — تجربة مباشرة | ❌ لا يحتاج مفتاح |
| `/data/v1/get` | authenticated GET | ✅ يحتاج `Ocp-Apim-Subscription-Key` |
| `/data/v1/getDa` | bulk download | ✅ يحتاج مفتاح |
| `/data/v1/getMetadata` | metadata | ✅ يحتاج مفتاح |

### 5.3 حدود الاستخدام (Rate Limits)

| Tier | الحد الأقصى | الحالة | ملاحظات |
|------|-------------|--------|---------|
| Preview API | 500 سجل/طلب | **Assumption / Evidence Required** | لا يحتاج مفتاح |
| Free tier | 500 طلب/يوم، 100,000 سجل/طلب، 5 req/s | **Assumption / Evidence Required** | يحتاج تسجيل مجاني |
| Premium tier | 5,000 طلب/يوم | **Assumption / Evidence Required** | يحتاج اشتراك |

**ملاحظة:** الأرقام أعلاه غير مثبتة رسمياً من UN Comtrade docs. التقدير `~1 req/s` للـPreview API هو **احتياط تشغيلي فقط** وليس حداً رسمياً موثقاً. يجب التحقق من القيم الرسمية أثناء التنفيذ قبل G4.
