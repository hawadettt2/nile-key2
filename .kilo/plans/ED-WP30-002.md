# Engineering Decision: ED-WP30-002

**Title:** WP-30F Scope Clarification — Tasks 6.1–6.4 Only  
**Date:** 2026-07-16  
**Status:** Approved  
**Decision Owner:** WP-30 Architecture Team  
**Review Authority:** Project Governance Board  
**Related Work Package:** WP-30F — Company Knowledge Layer Interface  

---

## 1. Decision

The formal scope of WP-30F is limited to **Tasks 6.1 through 6.4** as defined in `.kilo/plans/wp30-implementation-plan.md` Section 6.

**Task 6.5** ("Decision Engine and Mission Planner can query knowledge") is **explicitly excluded** from WP-30F. It is deferred to a future work package.

No architectural decisions are changed by this ED.

---

## 2. Conflict Evidence

| Document | Phase 6 Tasks |
|----------|---------------|
| `.kilo/plans/wp30-implementation-plan.md` (L453–462) | 6.1, 6.2, 6.3, 6.4 |
| `.kilo/plans/1784079736812-wp30-architecture-compliance-review.md` (L554–562) | 6.1, 6.2, 6.3, 6.4, **6.5** |

The Architecture Compliance Review includes Task 6.5, while the Implementation Plan does not.

---

## 3. Resolution

Per document hierarchy established in `PLAN.md` Section 20.3:

1. `wp30-implementation-plan.md` is the authoritative execution plan for WP-30F.
2. It explicitly claims alignment with the Architecture Compliance Review (L542–550) and declares "all architectural decisions are resolved."
3. The Architecture Review's Task 6.5 is a **capability statement**, not a WP-30F deliverable. The existing stubs in `decision_engine/engine.py` and `mission_planner/planner.py` already satisfy interface-level conformance for this capability.
4. No code changes are required in Decision Engine or Mission Planner for WP-30F.

---

## 4. Impact

- WP-30F implementation proceeds with **Tasks 6.1–6.4 only**.
- Task 6.5 is **out of scope** for WP-30F and must not be executed as part of this work package.
- Future work packages may address Task 6.5 if required.
- The Architecture Compliance Review should be updated in a future revision to reflect this scope decision, but this ED serves as the authoritative override until that update occurs.
