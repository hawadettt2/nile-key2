# WP-09 Execution Plan — SQL UPDATE Helper Refactor

**Project:** Nile Key Platform
**Baseline:** 0465c6a
**Status:** Ready for implementation

---

## Objective

Eliminate the remaining 6 manual SQL UPDATE statements by extending the existing `execute_update()` helper to support hardcoded field assignments, then routing each manual UPDATE through that single helper.

## Scope

**In scope:**
- `backend/app/core/database.py` — extend `execute_update()`
- `backend/app/routers/customers.py` — 1 endpoint
- `backend/app/routers/customs.py` — 1 endpoint
- `backend/app/routers/invoice.py` — 2 endpoints
- `backend/app/routers/resources.py` — 1 endpoint
- `backend/app/routers/suppliers.py` — 1 endpoint

**Out of scope:**
- API contracts
- Schemas / response models
- Frontend
- Authentication
- Database schema
- Business logic
- Any router not listed above

## Approach

Extend `execute_update()` with an optional `extra_fields` parameter.

**Behavior rules:**
1. Existing callers continue working without modification.
2. `data` provided: current behavior unchanged (`model_dump(exclude_unset=True)`).
3. `data is None`: do NOT call `model_dump()`. Initialize an empty update payload, then apply `extra_fields`.
4. `extra_fields` provided: merged into update payload.
5. Both provided: combined; `extra_fields` overrides duplicate keys.
6. `updated_at` auto-appended whenever helper executes an UPDATE.
7. SQL generation, parameter ordering, transactions, and return values unchanged.

**Helper signature change:**

Before:
```python
def execute_update(conn, table_name: str, record_id, data, coerce_fields: dict | None = None) -> bool:
```

After:
```python
def execute_update(conn, table_name: str, record_id, data, coerce_fields: dict | None = None, extra_fields: dict[str, Any] | None = None) -> bool:
```

Requires adding `from typing import Any` to `backend/app/core/database.py`.

**Concrete helper body change:**
Replace the current body with:

```python
    fields = []
    values = []
    coerce = coerce_fields or {}
    if data is not None:
        for field, value in data.model_dump(exclude_unset=True).items():
            if value is not None:
                fields.append(f"{field} = ?")
                if field in coerce:
                    values.append(coerce[field](value))
                else:
                    values.append(value)
    if extra_fields:
        for field, value in extra_fields.items():
            fields.append(f"{field} = ?")
            values.append(value)
    if not fields:
        conn.close()
        return False
    values.append(record_id)
    cursor = conn.cursor()
    cursor.execute(
        f"UPDATE {table_name} SET {', '.join(fields)}, updated_at = ? WHERE id = ?",
        (*values, datetime.utcnow().isoformat()),
    )
    conn.commit()
    conn.close()
    return True
```
