# Design System: Nile Key Public Website

**Project ID:** 14385331016044367049
**Scope:** The seven public marketing routes already present in the Stitch project — `/`, `/about`, `/products`, `/services`, `/markets`, `/contact`, `/login`.
**Default language:** Arabic (RTL), authored Arabic-first with an English parity toggle.
**Purpose of this revision:** This document is the **unified target** for the seven pages. It exists to converge the accidental visual drift that accumulated between pages (four button systems, two hover accents, three heading sizes, an off-brand Login screen) onto one language — **without changing any page's content, structure, or function.**

---

## 0. What This System Unifies (and What It Deliberately Does Not)

| Unified across all seven pages | Preserved as a genuine per-page difference |
|---|---|
| Palette roles and the single interactive accent | `/` hero: full-bleed Egyptian photographic scene (pyramids, port, produce) |
| Type scale: 34px page title, 28px section heading, 14px body | `/` section rhythm driven by explicit pixel heights at 1024px |
| Primary button (pill, mint) and secondary (outline ghost) | `/products`: 4:5 product cards with image scrim overlay |
| Card, input, and radius rules | `/contact` & `/login`: live forms with validation and submitting/success/error states |
| Shared Navbar and Footer rules | `/login`: authentication flow (login + register + pending-approval) — a functional mode, not a style |
| Content container width | Two light bands on `/` (Export Journey, closing CTA) used once each for contrast |

**Rule for every change:** alter colour, type, radius, and shared-component chrome only. Never remove, reorder, or add content, sections, fields, or routes.

---

## 1. Visual Theme & Atmosphere

A **deep Nile teal commercial authority**: a dark, saturated green-teal canvas (`#022F32`) that reads as serious, agricultural, and Nile-rooted rather than corporate blue. Sections alternate between two closely related teals (`#022F32` and `#043B3E`) to create quiet vertical rhythm without hard borders, and a **single emerald-mint accent (`#19D8B0`)** carries every interactive intent — CTA, hover, focus, active state, icon tint.

The register is photography-forward but currently restrained: only the `/` hero shows full-bleed Egyptian imagery. Every other page is built from dark translucent glass panels (`bg-white/5` fills, `white/10` hairlines). Where imagery has not been supplied, the code uses explicit `data-asset-gap` aspect-locked placeholders rather than stock substitutes — an intentional, honest gap.

Arabic typography runs through the system sans stack with `font-feature-settings: "rlig" 1, "calt" 1` so Arabic ligatures and contextual forms shape correctly. Layout uses CSS logical properties (`ms-`, `ps-`, `start-`, `-end-`) so RTL mirrors correctly with one stylesheet.

## 3. Typography Rules

### Font Families
**`system-ui / ui-sans-serif`**, no custom webfont, with `font-feature-settings: "rlig" 1, "calt" 1` on `body`. Character: neutral, modern, high-x-height — chosen for Arabic legibility at small sizes rather than personality. Latin display text uses the identical stack so both languages feel like one voice. **No new font family is introduced by this unification.**

### Hierarchy & Weights (one scale for all seven pages)
| Level | Size / Weight | Line-height | Usage |
|---|---|---|---|
| **Page title (H1)** | `34px` / `700` bold | 40px | Page-level titles on `/about`, `/products`, `/services`, `/markets`, `/contact`, and `/login` |
| **Section heading (H2)** | `28px` / `800` extrabold | 32px | **Every section heading on every page** — replaces the previous 28px vs 34px split |
| **Hero company name (H1, `/` only)** | `28px` / `800` extrabold | 32px | Arabic + English company block; the `/` hero is the single deliberate exception to 34px because its band is height-locked |
| **Card title (H3)** | `18px` / `600` semibold | 28px | Cards, contact info, form success |
| **Eyebrow** | `14px` / `600` / `uppercase tracking-[0.14em]` | 20px | Section eyebrows |
| **Lead paragraph** | `16px` / `400` / `leading-7` | 28px | Long-form company copy |
| **Body** | `14px` / `400` / `leading-6` | 24px | All general body copy |
| **Meta** | `12px` / `400` | 20px | Footer links, copyright, tile labels |
| **Nav link** | `13px` / `500` medium | 20px | Header navigation |
| **Button** | `16px` / `600` semibold | 24px | Primary and secondary CTAs; header auth buttons `14px` |

### Spacing Principles
Built on a **4px unit**. Paragraph separation uses `mt-2`/`mt-3` (8–12px); heading-to-body uses `mt-6` (24px) on inner pages and tighter `mt-2` on the landing page, which is intentionally denser. Word-spacing is never adjusted — Arabic is spaced naturally. **No type sizes, weights, or line-heights are changed as a side effect of this unification; only the duplicated levels converge.**

## 5. Component Stylings

### Buttons — one primary, one secondary (replaces four systems)
| Variant | Rule | Applies to |
|---|---|---|
| **Primary (mint pill)** | `h-12 rounded-full bg-[#19D8B0] text-[#022F32] px-8 text-base font-semibold`, hover `bg-[#19D8B0]/90` | Every page-level CTA across all seven pages — **including `/` hero and `/login`**, replacing the white/gradient/dark/emerald variants |
| **Secondary (outline ghost)** | `border-white/70 bg-transparent text-white hover:bg-white/10 hover:text-white` | Header *create account*; secondary actions |
| **Icon pairing** | 16px icon + `ms-2` (16px) logical gap, so the icon flips correctly in Arabic | All buttons |

Retired by this unification: `rounded-md` + `bg-white`/gradient on the `/` hero, `rounded-full bg-[#073a3a]` on the `/` closing CTA, and `rounded-lg bg-emerald-600` on `/login`.

### Cards & Containers
- **Feature / info cards:** `rounded-2xl border border-white/10 bg-white/5 p-6` — dark translucent panels, hairline borders, no shadows.
- **Product cards (preserved difference):** `rounded-xl border border-white/10 bg-white/5` with a `4:5` aspect image area, a bottom `h-2/3` gradient scrim (`rgba(2,47,50,.85) → transparent`), and text overlaid on the scrim in `p-5`. The 4:5 ratio and scrim are product-specific and are kept.
- **ServiceCard / MarketStepCard:** converge onto the shared card rule above — `#19D8B0` icons (was `emerald-400`), `white/60` body (was `slate-400`), `rounded-2xl border-white/10 bg-white/5 p-6`; MarketStepCard keeps its oversized ghost step-number at `text-4xl` in `white/10` opacity.
- **Accent offset blocks:** the `/about` page's offset `rounded-2xl` block (`-bottom-6 -end-6`, `bg-[#022F32]`) is retained — it is a deliberate depth device.

### Inputs & Forms (Contact + Login)
- Fields: `rounded-xl border border-white/10 bg-[#022F32] px-4 py-3`, `placeholder:text-white/40`.
- **Focus:** outline removed, border switches to `border-[#19D8B0]` — a single-colour focus signal, no ring. (This replaces `focus:ring-2 focus:ring-emerald-500` on `/login`.)
- **Error:** `border-red-400` plus `mt-1 text-sm text-red-400`; required asterisk `text-red-400`.
- Submit is the primary mint pill (full-width inside the form); success replaces the form with an accent-titled panel.
- **`/login` surface change:** the white card on a slate gradient is replaced by the shared glass card on `#022F32` — `rounded-2xl border border-white/10 bg-white/5`, `text-white` labels and body. The login/register toggle, pending-approval notice, and all validation behaviour are unchanged.

### Radius System (one rule, retired the ad-hoc mix)
| Element | Radius |
|---|---|
| Buttons (primary & secondary) | `rounded-full` (9999px) |
| Cards & containers | `rounded-2xl` (1rem) |
| Product cards, inputs, mobile menu rows | `rounded-xl` (0.75rem) |
| Logo mark, inner panels | `rounded-lg` (0.75rem) |
| Chips, pills, hairline indicators | `rounded-md` (0.375rem) |
| Timeline nodes, icon badges | `rounded-full` |

The `--radius: 0.75rem` root variable remains the base; component radii are now assigned by the table above rather than chosen ad hoc per component.

### Domain-Specific Components
- **Export journey timeline (unified size):** a `h-[3px] bg-white/15` horizontal track with **56px (`h-14 w-14`)** circular nodes (`rounded-full border border-white/15 bg-[#022F32]`, `#19D8B0` icons at 22px) and 18px chevron arrows in `#19D8B0` marking direction. The `/` hero previously used 44px (`h-11 w-11`) nodes; **56px is the single standard** and `/` moves up to it. Collapses to a vertical timeline at `md` with `ChevronDown` connectors.
- **`/` feature tiles:** keep their compact form (`min-h-[78px] rounded-xl border-[#0c6558]/60 bg-[#032f30]/30`, 28px `#4EE58E` icon, `text-sm` bold title, `text-xs` body) — these are intentionally denser than inner-page cards because the `/` platform section is height-locked.
- **Stat blocks:** `text-3xl`–`lg:text-[36px]` bold numerals in `#19D8B0` with `text-sm white/60` labels, separated by a `border-s border-white/10 ps-8` hairline.
- **Logo mark:** `h-9 w-9 rounded-lg` with the `#22BD75 → #0CA55F` gradient and "NK" in `text-sm font-extrabold`; identical in navbar and footer, and adopted by `/login` in place of `bg-emerald-600 rounded-2xl`.

## 6. Layout Principles

### Grid & Structure
- **Content width:** `w-[min(92vw,1280px)]`, `mx-auto` — **one value for the body and the footer across all seven pages** (footer widened from `w-[min(88vw,1200px)]`; the `/` page keeps its tighter `w-[min(86vw,1280px)]` inner measures where it is height-locked).
- **Grids:** card grids `md:grid-cols-2 lg:grid-cols-3` with `gap-8`; two-column text/image blocks `lg:grid-cols-2` with `gap-12`–`gap-16`; markets timeline `grid-cols-6` with `gap-4`.

### Whitespace Strategy
- Base unit **4px**. Inner-page sections `py-14` (56px) mobile / `md:py-20` (80px) desktop — generous and uniform across the six non-hero pages.
- The `/` page remains deliberately denser, driven by explicit target section heights at 1024px: Hero 402px, Our Company 243px, Export Journey 254px, Digital Platform 381px, Global CTA 141px, Footer 115px. **These heights are not altered by this unification.**
- Card padding `p-6` (24px); product card overlay text `p-5`.

### Alignment & Visual Balance
- `/about`, `/products`, `/services`, `/markets`, `/contact` heroes are **centre-aligned** with a `text-base white/70` subtitle.
- The `/` hero is a **right-aligned Arabic text block** over a full-bleed left photographic scene — text occupies the right ~43%, imagery the left. This asymmetry is the page's signature and is preserved.
- Section backgrounds alternate `#022F32` / `#043B3E` rather than using borders.
- `/login` centres a single `max-w-md` form card in the viewport.

### Responsive Behaviour & Touch
- **Breakpoints:** Tailwind defaults — `sm` 640, `md` 768, `lg` 1024, `xl` 1280. Mobile-first.
- Desktop nav collapses below `lg` to the hamburger; the markets timeline flips from horizontal to vertical at `md`.
- Minimum touch target: the 48px `h-12` primary CTA (44px header buttons, ~38px nav toggle) — unchanged by this unification.
- The `/` page uses `lg:`-prefixed explicit pixel heights, falling back to natural vertical flow below `lg` (Hero `min-h-[480px]`).
